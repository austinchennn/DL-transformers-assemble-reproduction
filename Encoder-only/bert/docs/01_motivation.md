# 01 · BERT 的动机

## 1. 背景：2018 年之前的两条路线

在 NLP 中利用无标注语料做预训练，当时主要有两种方式：

| 路线 | 代表 | 做法 | 问题 |
| --- | --- | --- | --- |
| **Feature-based** | ELMo | 预训练一个双向 LSTM 语言模型，把隐状态作为**特征**拼到下游任务模型里 | 下游仍需设计专门的模型结构；“双向”其实是两个单向模型的**浅层拼接** |
| **Fine-tuning** | OpenAI GPT | 预训练一个 Transformer Decoder 语言模型，下游任务直接在其上**微调** | 语言模型是**从左到右**的，每个 token 只能看到左边的上下文 |

## 2. 核心问题：单向性

标准语言模型的目标是 $P(x_t \mid x_{<t})$，天然只能单向。可很多理解类任务需要同时看左右两边：

> “他把 **___** 存进了银行，然后去河边钓鱼。”

要判断“银行”的含义、或者填出空白，右侧上下文同样重要。

为什么不能直接做“双向语言模型”？因为在多层的双向结构里，每个词会**间接看到自己**——第 2 层位置 $i$ 的表示来自第 1 层所有位置，而第 1 层其他位置已经包含了 $x_i$ 的信息，预测 $x_i$ 就变成了抄答案。

## 3. BERT 的解决办法

1. **Masked Language Model (MLM)**：随机遮住一部分输入词，让模型根据**左右两边**的上下文去预测它。被遮住的词不在输入里，就不存在“看到自己”的问题，于是可以使用**深层的、真正双向的** Transformer Encoder。
2. **Next Sentence Prediction (NSP)**：问答、自然语言推断等任务需要理解**两个句子之间的关系**，语言模型目标学不到这一点，因此加入一个二分类任务：B 句是否紧跟在 A 句后面。
3. **统一的预训练 + 微调范式**：预训练和下游任务使用**同一套结构**，下游只在顶部加一个很小的输出层，所有参数一起微调。不需要为每个任务设计专门的网络。

## 4. 影响

- BERT 刷新了 11 项 NLP 任务的 SOTA（GLUE、SQuAD、SWAG 等）。
- 确立了“大规模无监督预训练 + 少量有标注数据微调”的范式。
- 后续改进很多：RoBERTa（去掉 NSP、动态掩码、更多数据）、ALBERT（参数共享）、ELECTRA（替换词检测）、DeBERTa（解耦注意力）等。
- 今天 Encoder-only 模型主要用于 Embedding / 检索 / 分类，如 BGE、text-embedding 系列。

## 5. 与 GPT 的对比

| | BERT | GPT |
| --- | --- | --- |
| 结构 | Transformer **Encoder** | Transformer **Decoder** |
| 注意力 | 双向（全可见） | 因果（只看左边） |
| 预训练目标 | MLM + NSP | 下一个词预测 |
| 擅长 | 理解：分类、抽取、检索 | 生成 |
| 能否直接生成文本 | 不擅长 | 可以 |
